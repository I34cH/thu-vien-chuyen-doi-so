Quy trình: dùng invoke_subagent Model "flash" với 3 subagent KHÁC NHAU: IMPLEMENT, TEST (chạy đúng LỆNH KIỂM CHỨNG của M6 trong 01-teamwork.md; Windows: DATABASE_URL trong .env, đặt PGCLIENTENCODING=UTF8), AUDIT (đối chiếu AGENTS.md: phân quyền yeuCauVaiTro, SQL tham số $1, cờ du_lieu_mau, màu đỏ, phạm vi; liệt kê lỗi cho implement sửa). Lặp implement -> test -> sửa tối đa 3 vòng; quá 3 vòng thì làm theo /boost (nguyên nhân gốc, 2 cách sửa, chọn 1). Ghi reports/milestones/M6.md: file đã tạo/sửa, output lệnh kiểm chứng dán NGUYÊN VĂN, kết quả audit, vấn đề còn lại.
Sau khi gọi subagent, kết thúc lượt để chờ hệ thống đánh thức (tiến trình được giữ sống). Không hỏi lại người dùng.
