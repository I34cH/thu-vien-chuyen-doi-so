# M3 — Backend API (`server/`)

- **Trạng thái:** xong (PASS)
- **Số vòng sửa:** 2 (Vòng 1: xây dựng khung API, bảo mật và 21 ca kiểm thử ban đầu; Vòng 2: hoàn thiện xử lý dấu gạch chéo đường dẫn trên Windows, loại bỏ cột nội bộ `tsv` trong chi tiết tư liệu, siết chặt Path Traversal với `path.sep`, bổ sung kiểm tra hạn trả ~14 ngày, thêm sweep dự phòng sau test và bổ sung kiểm thử cho 4 route còn lại nâng tổng số ca test lên 25/25)
- **File tạo/sửa:**
  - `server/db.js`: kết nối PostgreSQL qua `pg.Pool`, đọc `DATABASE_URL` từ file `.env` qua `dotenv`, đặt `PGCLIENTENCODING=UTF8`.
  - `server/middleware/auth.js`: cấu hình session, middleware `yeuCauVaiTro(...)` kiểm tra phân quyền (`*`, `nguoi_dung`, `thu_thu`).
  - `server/app.js`: khởi tạo Express, gắn session, static `public/`, các router API và bẫy lỗi 404 trả về JSON chuẩn xác.
  - `server/routes/auth.js`: xác thực tài khoản (`POST /dang-nhap`, `POST /dang-xuat` an toàn chống null session, `GET /toi`), hỗ trợ trường `nhom_vai_tro` tiện ích.
  - `server/routes/taiLieu.js`: tra cứu công khai (`GET /gioi-thieu`, `GET /goi-y`, `GET /tim-kiem` khống chế độ dài chuỗi q chống DoS, `POST /tim-kiem/:logId/chon`, `GET /tai-lieu/:id` không trả về cột nội bộ `tsv`, `GET /ban-mem/:id` chống triệt để Path Traversal bằng `path.sep`).
  - `server/routes/muon.js`: nghiệp vụ mượn sách cho người dùng (`POST /muon`, `GET /muon/cua-toi`, chặn đăng ký trùng cho cùng tư liệu).
  - `server/routes/quanLy.js`: thủ thư duyệt/từ chối/trả mượn trong transaction và upload file PDF (chỉ nhận PDF, kiểm tra header `%PDF`, chuẩn hóa tiền tố và dấu gạch chéo bảo vệ tuyệt đối tệp mẫu `mau/`).
  - `server/routes/thongKe.js`: tổng hợp dashboard thủ thư (`/tong-quan`, `/tu-khoa`, `/theo-ngay`, `/khong-ket-qua`, `/nen-so-hoa`), tuyệt đối không để lộ dữ liệu cá nhân hay `ma_phien`.
  - `server/tests/api.test.js`: bộ kiểm thử tự động 25 ca kiểm tra sâu tất cả các luồng nghiệp vụ, kiểm tra hạn trả ~14 ngày, tự động sweep dọn sạch rác sau khi test.
  - `reports/milestones/M3.md`: báo cáo kiểm chứng milestone M3.
